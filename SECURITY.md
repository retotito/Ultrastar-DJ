# Security

Found a security problem in Ultrastar DJ — for example in the guest songbook, which is reachable from other phones
and, with a public link, from the internet? Please report it privately, not as a public issue:

**Security → Report a vulnerability** on <https://github.com/retotito/Ultrastar-DJ/security>.

Only the newest version gets fixes. You will get an answer as soon as possible; this is a project run in spare time.
